# Review an animation

Use `$review-obs-overlay` to review `src/<animation-id>/` without changing
files. Check the source, its `CONFIG.md`, the demo entry, and the README entry.

Report only actionable findings, ordered by severity. Cover OBS transparency,
repeat triggers and cleanup, resizing, Twitch command safety, preview support,
documentation/default drift, the four required script dividers, and concise
comments above named functions. State explicitly when no issues are found.
